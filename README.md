# Ludo independent creator funnel

URL: https://ludo-creator-funnel.vercel.app/ludo

Edit config/site.config.json and replace photo placeholders in public/images. Turnstile must be enabled with a site key in config and TURNSTILE_SECRET_KEY in Vercel project env. Both creator profiles use the same provided Fanvue destination https://www.fanvue.com/wisterya. Tracking disabled by default. Replace privacy email before production use.
